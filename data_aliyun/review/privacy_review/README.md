# 项目隐私去标识化审查

审查日期：2026-11-01。

## 范围与结果

审查当前项目工作目录内的全部普通文件（含隐藏文件），对文本、Notebook、二进制字节及 ZIP 成员展开检查。Git 历史不在本次修改范围内；不修改工作目录之外的其他项目、系统配置和原始对话记录。

发现的个人信息主要是本机用户目录、个人账号名、Conda 安装位置、临时目录，以及包含这些信息的编译记录和 Python 缓存。已完成以下处理：

- 31 个原有文本文件中的个人路径去隐；项目内 Markdown 链接改为相对于文档位置的路径，JSON 中的项目路径使用相对路径。
- 两个实验 Notebook 使用运行时发现项目根目录的方式定位数据，不再依赖固定个人目录；相应生成脚本已同步修正。
- 环境检查只记录解释器名称；报告中运行命令使用 `python`，历史环境路径使用通用标记。
- 清理 32 个可重新生成的 Python 缓存文件，避免字节码继续携带旧绝对路径。
- 旧版和审查版两份论文 ZIP 均已处理，包内摘要和审查版整体摘要已更新；当前审查版包还附带隐私修订记录。

该处理是路径及运行环境标识去隐，不是对研究数据进行统计匿名化，也不对自由文本、图片像素或加密/任意序列化内容作不存在个人信息的保证。邮件形态模式在模型二进制中命中的是随机字节，未据此改写模型。没有发现文本邮箱或私钥头部。
