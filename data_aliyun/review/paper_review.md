# paper.ipynb 审查与改进建议

## 结论

这是以体检指标预测连续血糖值的回归任务，评价应使用 MSE/RMSE，而不是分类准确率。探索分布、建立线性基线、比较非线性模型的方向合理；但目前验证设计、年龄处理和中间文件依赖，使现有模型比较不足以证明泛化提升。优先修复评估流程，再比较原始特征上的提升树，收益比扩大网格更值得验证。

本次没有修改 paper.ipynb。新增 baseline_check.py 与 baseline_results.json，记录实测对照。

## 按优先级排列的问题

### P1：划分之前拟合预处理，验证集参与了训练流程

位置：单元格 22、33、40、43；paper.ipynb JSON 行 1269、2206、2966、3043。

均值填补、StandardScaler、PCA 全在 train_test_split 之前拟合；后续 GridSearchCV 的各验证折也已参与这些变换。这里主要是特征分布泄漏，不应误称为把血糖直接放进特征。单元格 34 的 Lasso 也看到了全部标签；如果据此挑选特征，进一步造成监督式选择泄漏。

修复：先划分，再在每个训练折内拟合 imputer/scaler/selector/PCA；使用 Pipeline 纳入交叉验证。验证折只能 transform。泄漏影响大小必须用纠正后的实验测量，不能预设降低了多少 MSE。

### P1：将标准化后的年龄转整数，损失有效预测信号

位置：单元格 33；JSON 行 2208–2209。

实测清洗后的年龄有 74 个取值，标准化再 astype(int64) 后只剩 7 个值；向零截断会把均值附近一大段年龄压成 0。这会损害年龄梯度和阈值信息。

性别的标准化值实际约为 0.9334 / -1.0714，转整数后成为 0 / -1，仍保留两类，并非全部变成 0。该写法依赖男女占比，没有必要；应显式映射女=0、男=1、未知作为独立类别或缺失标记。年龄标准化后保持浮点数；树模型直接使用原始年龄。

### P1：删除大量缺失样本后评估，无法代表完整预测人群

位置：单元格 22、27；JSON 行 1262–1266。

train+A 共 6642 行，删除 1 条未知性别，按缺失率再删除 1427 行，按特征阈值再删除 12 行，剩 5202 行。缺失筛选删除约 21.5% 原始样本；其血糖均值约 5.5173，而保留组为 5.6851，已经改变了评估人群。

修复：预测和最终评分保留全部行；缺失较多的记录使用缺失标记与可处理 NaN 的模型，或折内中位数填补。先保留乙肝指标做有/无消融，不因缺失多和线性相关低就判定无用。对极端检验值，区分录入错误与真实高风险样本；没有证据时不要批量删行。禁止靠删除高血糖样本改善 MSE。

### P1：用于选择模型的集合被当作最终测试集

位置：单元格 49、60、61；JSON 行 3543、3836 起。

神经网络反复观察同一集合的 validation loss；XGBoost 更直接在该集合上比较 30–50 轮，再报告 40 轮最佳结果。这属于验证集选型，不能同时用作最终泛化成绩。train+A 的合并本身可以作为扩充训练的策略，但此时 A 已不再是外部测试集。

修复：原始 train 内完成交叉验证和早停；A 用于一次外部检查；B 在方案冻结后评估一次。若依据 A 结果继续调整，就明确把 A 记作开发集。B 本次已被查看及评估，后续继续依 B 调参就不能声称它仍是完全未触碰的最终测试集。

### P2：修改前面的预处理不会自动进入后面的训练

位置：单元格 41、43；JSON 行 3007–3008、3043–3044。

PCA 与 target 的写出被注释，训练重新读取旧 CSV。即使修正年龄或改动预处理，训练仍可能使用旧文件，使优化实验失效。当前 target.csv 的 5202 个值及索引与按现有清洗步骤复现的目标一致；未据此证明 PCA 文件与当前变换完全一致。

修复：直接使用本轮内存数据，保存整个训练 Pipeline。PCA 表重建连续索引、target 保留删行后索引，当前 train_test_split 是按位置配对，因此未发现这一处已经错配；但后续按索引 concat/join 会有风险，应以原始 id 明确核对。

### P2：特征压缩和搜索策略与预测目标不匹配

位置：单元格 37–40、53–60。

解释 98% 特征方差不等于保留 98% 血糖预测信息；KMO/Bartlett 不能证明 PCA 会改善预测。树模型在 PCA 后的旋转轴上切分，也可能更难表达原始检验指标的阈值。应以同折验证比较原始特征、筛选特征、PCA 三种方案。

决策树随机搜索 3000×5 次拟合；XGBoost 网格为 729×5 次拟合，仍另外扫描轮数。单元格 54/60 手填参数，而非使用搜索返回对象，容易与实际最优结果不一致。建议以固定随机种子的 20–40 组合理参数和训练折内早停取代大网格。模型选择与报告分数最好采用外层验证，或明确标注调参后的 CV 存在选择偏差。

## 数据核验

- train：5642 行，42 列；A/B 各 1000 行，41 列。
- A 答案首行为 `???` 表头，默认读取得到 1000 个答案。
- B 答案首行为 `5.26`，没有表头，必须 `header=None`；默认读取只有 999 个答案，会丢失首个值并造成对齐风险。当前 notebook 尚未使用 B，因此这是后续评估必须避免的问题。
- train 内排除 id 后未发现完全相同的重复行；这不证明不存在同人多次体检，因为没有患者身份键。
- train/A/B 的 id 区间依次递增，体检日期分布也有区别。因此应增加按日期或日期区间留出的验证，检查随机划分是否高估跨批次表现。日期可尝试批次特征，但必须通过这种验证；id 默认只用于对齐，不直接入模。

## 本次实测

环境没有 scikit-learn、XGBoost、CatBoost；尝试安装 scikit-learn 时网络域名解析失败，因此没有重跑原 notebook 或提升树。对照使用现有 numpy/pandas 实现岭回归。

协议：只用原始 train 的五折验证选择参数（随机种子 23）；折内中位数填补、增加各特征缺失标记、折内标准化；不删除样本，不做 PCA，不按答案筛选样本。比较 alpha=10/100/1000，以及有/无年龄折线和三个检验值 log1p 特征，共六组；只在训练集 CV 上选择。最终均用原始 train 拟合，分别评估完整 A/B，没有根据 A/B 结果再次选型。

| 模型/集合 | MSE | RMSE | MAE | R² |
|---|---:|---:|---:|---:|
| 岭回归，train 五折 OOF | 2.00891 | 1.41736 | 0.77869 | 0.15813 |
| 岭回归，完整 A | 1.79247 | 1.33883 | 0.77017 | 0.14503 |
| 训练均值预测，完整 A | 2.10934 | 1.45236 | 0.75687 | -0.00611 |
| 岭回归，完整 B | 1.37905 | 1.17433 | 0.71325 | 0.10199 |
| 训练均值预测，完整 B | 1.55671 | 1.24768 | 0.71995 | -0.01370 |

所选为无附加非线性特征、alpha=100。相对均值预测，A/B MSE 分别下降约 15.0% / 11.4%。A 的 MAE 反而略差，说明优化 MSE 不保证同时优化 MAE。附加的年龄/对数特征没有带来 CV 改善，不建议直接采用。CV 是用于六组选型的分数，不是无偏的最终成绩；未开展多随机种子稳定性或置信区间分析。

**不能把 B 的 1.37905 与 notebook 的 1.66057 直接比较并宣称提升**：两者数据集合、筛选条件和训练协议不同。该实验建立的是完整样本、无预处理泄漏的基准。

复现：在有 numpy/pandas 的 Python 环境中运行 `python3 review/baseline_check.py`，会写出 review/baseline_results.json。

## 下一轮最值得做的实验

1. 冻结评价口径：MSE 主指标，RMSE/MAE/R² 辅助；所有候选共享同一折划分。保留按日期留出的压力测试，报告完整样本成绩。
2. 原始特征上的 HistGradientBoosting、CatBoost 或 XGBoost 对比岭回归。先不做 PCA，保留年龄、缺失模式，使用平方误差目标。控制树深度/叶节点数、较大叶子样本数、正则化和训练折内早停；具体参数由 CV 决定。优先尝试这一类模型，尚无证据保证一定优于基线。
3. 消融：保留/移除乙肝指标、缺失标记、日期、少量合理比值及计数特征。比值要处理分母为零和极小值，所有需要估计阈值的处理限定训练折。每次只改变一个因素；记录平均 MSE、各折误差及稳定性。
4. 用 OOF 残差按年龄、性别、缺失程度和血糖区间定位误差来源，尤其查看少量高血糖样本对总平方误差的贡献。按真实血糖分组仅用于事后诊断，不能用于推理分流。不要直接使用真实血糖段作为预测特征。
5. 只有当提升树与岭回归的 OOF 残差互补时，尝试少量加权平均；权重限定开发数据确定。不要先引入复杂堆叠。
6. 神经网络作为次要对照：固定随机种子，减小网络与 Dropout，比较合理 batch size，使用 EarlyStopping(restore_best_weights=True)。这些调整仍需实测；约五千条表格数据不足以据网络规模判断谁必然最优。

若以 MSE 为目标，不能简单认为对血糖取 log 再 exp 能降低误差：反变换一般不直接给出原尺度条件均值。Huber/MAE 也改变目标，应作为对照而非默认替代平方损失。
