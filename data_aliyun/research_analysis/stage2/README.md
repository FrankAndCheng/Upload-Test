# 第二阶段：论文结构设计

已依据用户提供题目和第一阶段核对结果完成[论文结构设计](论文结构设计.md)。本目录不含论文正文、LaTeX工程或PDF。

结构设计包括：

- 论文定位、主方案与历史协议的安排。
- 摘要、九个正文研究章节、参考文献及附录的逐节任务。
- 研究任务的“分析—模型—求解—结果解释”对应路径。
- 公式/符号/伪代码、正文图表及附录分工。
- 证据映射、结论边界、篇幅比例及未提供信息的处理。

正文主线为“基准比较—顺序优化与四模型融合—预处理对照—误差检验”，使用当前完整样本协议。历史H1/H2单独放附录，未完成的效率/解释性/敏感性实验不补造。

第一阶段材料入口：[研究梳理与证据](../stage1/README.md)。本阶段没有改变既有研究方法或实验结论，也未进入第三阶段。
