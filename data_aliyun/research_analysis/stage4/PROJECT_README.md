## 编译

推荐XeLaTeX。使用ctexart、Fandol中文字体、A4纸及常用数学、三线表、跨页表、图片和超链接宏包。未提供官方模板，因此目前是通用中文学术论文排版，不声称已满足某一官方页数或匿名格式。

在主入口所在目录执行两遍：

```bash
xelatex -interaction=nonstopmode -halt-on-error paper_body.tex
xelatex -interaction=nonstopmode -halt-on-error paper_body.tex
```

若使用带自动多遍编译的编辑器，选择主入口即可。当前桌面编辑器已对这一主入口返回编译成功。首次运行曾因编译环境初始化及字体/宏包下载超时，资源缓存后第二次调用成功。

文献仍沿用第三阶段已核验的thebibliography条目，避免模板尚未确定时引入额外文献后端；`references.tex`是本工程实际输入。`references.bib`包含相同的11个引用键，便于以后换官方模板时使用。仅修改bib文件不会自动改变当前参考文献；编辑文献时应保持两文件一致，或明确切换文献后端。
