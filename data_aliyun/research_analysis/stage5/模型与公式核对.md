# 模型、公式与实现核对

核对对象为论文中的23个编号公式及对应文字。单元格按Notebook的cells数组从1计数。公式内容未新增算法；代码推导的数学表达与保存结果分开核对。以下“通过”指未发现与指定实现的核心冲突，不代表对所有可能输入完成形式化证明。

| 公式标签 | 核对重点 | 来源与结论 |
| --- | --- | --- |
| eq:mse | 平方误差按评价行数平均；目标为连续血糖 | 竞赛要求；主C046/C052/C069；通过。正文区分未舍入研究指标与三位提交格式。 |
| eq:impute | 拟合行中位数、自动缺失指示、全空列保留并填0 | 主C023/C038；顺序preprocess；通过。未知性别标记和自动指示可能重复，忠实保留。 |
| eq:scale | 方差分母为n；不缩放目标；数值保护 | 主C034/C038；实际StandardScaler；通过。第五阶段补充近常量列保护说明。 |
| eq:pca | 中心化、完整SVD、累计比例严格超过0.98 | 主C038/C040；预处理preprocessing；通过。不同拟合集的维数不强行设为29。 |
| eq:ols | 含截距的残差平方和；40维填补探索输入 | 主C031；通过。训练拟合指标不作开发/B预测成绩。 |
| eq:lasso | 1/(2n)残差平方和加L1；alpha=0.05 | 主C035；通过。系数排序不等于最终融合解释或因果影响。 |
| eq:auxiliary | RMSE、MAE及以评价集目标均值为基准的R² | 顺序score、主C069；通过；保存预测复算覆盖可得记录。 |
| eq:oof | 各种子先合并行计算MSE，再平均两个种子的损失 | 顺序cv/confirmation；通过。区分基准搜索的等权折均值和后续合并OOF均值。 |
| eq:ridge | 残差平方和加100倍L2；截距不惩罚 | 主C046及冻结配置；通过。没有将损失错误改为均值后仍保留同一惩罚解释。 |
| eq:tree | 平方误差树叶均值；随机森林叶样本计入抽样频数 | 主C054/C064；通过。不虚构全局最优树结构或线性约束。 |
| eq:forest | 200棵树输出等权平均 | 主C064及冻结配置；通过。没有引入未开展的OOB验证。 |
| eq:ada | AdaBoost.R2指数误差、样本权重更新、加权中位数输出 | 主C057/C058、实际_weight_boosting实现；通过。补充均匀初始权重，300为上限而非保证有效树数。 |
| eq:xgb | 半平方损失的梯度/Hessian、叶数/L2/L1正则 | 主C060、顺序estimator与冻结参数；通过。学习率缩减在后续更新说明。 |
| eq:ratio | 分母>1e-6才取比值；分子缺失传播 | 顺序features；通过。未写成分母统一加epsilon。 |
| eq:counts | 白细胞计数乘细胞百分比除以100 | 顺序features；通过。称估算计数而非独立采集变量。 |
| eq:additive | 提升树加性表示；求解、缺失路由各按实现 | 顺序estimator；通过。未增加GOSS/EFB/GPU贡献实验。 |
| eq:smallnn | 小批次MSE加指定隐藏Dense核L2=0.001 | 顺序build_nn/fit_nn_predict；通过。无偏置或输出层核的L2，不把Dropout用于推理。 |
| eq:weights | 仅在有限权重集合比较；权重非负且和为1 | 顺序树/线性融合及complete_nn_blends；通过。不是连续单纯形优化或二层学习器。 |
| eq:final | 小网络25%加三模型75%，展开四成员各25% | frozen_selection的nn_blend_06/blend_33；通过。开发/B逐行加权恒等式已重新核对。 |
| eq:improvement | 同一评价集基线减候选，再除以基线 | evaluation/stage_comparison；通过。论文六位比例使用保存指标，CSV往返误差单列。 |
| eq:replacement | 0.5%相对改善与10折至少7胜，含1e-12门槛 | 预处理run_ablation；通过。10个模型的决定均重新计算匹配。 |
| eq:paired | 同行候选平方误差减参考平方误差 | 顺序complete_nn_blends、预处理render_results；通过。按原随机数消耗顺序重现区间。 |
| eq:sse-share | 分箱SSE除以整个评价集合SSE | 顺序target_bands生成；通过。未作为预测分流或医学分类阈值。 |

最终配置核对：优化XGB393轮、深度5、原记录学习率和正则；LightGBM800轮/15叶/叶最少20/学习率0.015；Ridge惩罚100；去乙肝64—32小网络固定36轮、batch64、Adam0.001。四者分别保留自身输入处理，参考LightGBM为原生缺失。仅推荐预处理的另一个融合版本保留为对照，没有替换主方案。

数据与证据边界：主协议train+A共6642，固定4649/1993；B拟合全部6642。旧清洗样本H1、只用原train的H2、87轮旧大网络及后续清理状态重训实例均单列。两套五折、适应性网络补充和已知B复核没有被表述为新的盲测或完整嵌套验证。

详细来源仍见第三阶段来源核对表；当前校订与限制见[质量审查报告](质量审查报告.md)。
