# 论文LaTeX工程说明

主入口是本目录上一层的 `paper_body.tex`，仍为用户原已打开的文档。章节、表格、图片和文献使用相对路径；编译工作目录应为主入口所在目录，不应单独编译章节或表格文件。

第五阶段的经审查工程包名为 `glucose_latex_reviewed.zip`，位于原研究目录的 `research_analysis/stage5/`；第四阶段工程包保留为历史快照。包内的 `audit/` 和 `provenance/` 分别保存本次审查及来源登记。

## 内容

- 15份章节文件：摘要、九章正文、五个附录。
- 19张表，其中2张为跨页表。
- 论文显示11幅图；全部11幅原图均保留，相关热图改用按原训练探索步骤重排的版本，所以图片资源共12份。
- `tables/training_correlation_matrix.csv` 为重排热图对应的完整40×40矩阵，不是新增预测实验。
- `references.tex` 是实际排版的11条文献；`references.bib` 保留相同引用键供官方模板迁移。仅修改bib不会自动改变当前文献排版，编辑时应保持两文件一致或明确切换文献后端。

## 编译

推荐XeLaTeX。使用ctexart、Fandol中文字体、A4纸及常用数学、三线表、跨页表、图片、链接宏包。未提供官方模板，当前为通用中文学术论文排版。

在主入口所在目录执行两遍，或交由编辑器自动多遍编译：

```bash
xelatex -interaction=nonstopmode -halt-on-error paper_body.tex
xelatex -interaction=nonstopmode -halt-on-error paper_body.tex
```

第五阶段最后一次修改源文件后，当前编辑器的内置编译器已返回编译成功。过程中保留原主入口及编辑器，没有另建或打开替代文档。

## 检查与保留事项

23个编号公式和19张表的内容与原稿一致。1090项指标、122项额外区间/分箱/比例检查及10个预处理替换决定均核对通过；完整研究中的752个非系统元数据文件未变。相关热图仅重排，所有原图仍可追溯。表头和数值、资源、标签、引用及环境结构检查通过。

内置编译工具仅返回诊断，不导出PDF。此前界面访问被拒绝，本阶段尊重该限制，没有另行编译独立PDF。因此工程包不附未取得的PDF，也不声称已完成逐页视觉验收。最终页数、图表实际字号、长表分页、页眉页脚、孤立标题和溢出仍需在可读取的最终PDF上核验。

官方模板、页数/匿名规则、指标单位和采样条件、标签原始排序来源、竞赛提交表头/ID规范仍待确认。当前主研究使用A标签扩展训练，不将其已知集合复核成绩称为原初赛在线成绩。三位小数要求已在论文说明，本工程不修改算法或生成比赛提交文件。
